# DAY8 检索开发集

`retrieval-samples.json` 是 DAY8 的小型、人工标注开发集。它用于验证候选排序是否
能覆盖 Markdown、PDF、DOCX、XLSX 的真实定位；不包含用户私人资料，也不替代 DAY16
的 20 个核心任务与留出集。

## 执行口径

- 每次运行固定一个已发布快照，并记录配置、候选 Chunk ID、RRF 顺序、rerank 结果或降级原因。
- 相关性先按 Chunk 级评分；同一问题有多个等价位置时必须全部在 `expectedEvidence` 列出。
- 引用正确性与回答事实分开判断：命中正确 Chunk 不代表模型回答一定有依据。
- 此开发集可用于调参；发布结论必须另用未参与调参、按来源主题划分的留出集验证。

## 当前限制

当前仅定义了评测数据和运行口径，尚未实现自动评测脚本、百分比结果或质量宣称。没有
完整人工标注的相关证据集合时，不能将“候选命中数量”写成 Recall@K。
