## 交付

- 聊天输入区增加默认关闭的联网开关；新会话、切换会话和页面刷新后关闭。开启后模型按需选择搜索，不要求每条消息搜索；生成期间禁止切换。主动重试采用提交时当前开关状态。
- API 用 Schema 校验布尔值，将本轮选项写入 `run_started`。Workflow 从持久事件恢复授权，旧 Run 未记录时默认关闭。
- `lib/agent/tools.ts` 统一注册本地工具和获准使用的 `search_web: gateway.tools.perplexitySearch(...)`；直接由主模型调用，不再在工具内部套 `generateText`。空库也可开放联网工具。
- `lib/agent/web-search.ts` 只负责校验、去重和选择主模型收到的真实搜索结果，不发网络请求。既有 D10 最终回答生成阶段保持原职责。
- 搜索配置默认 5 条结果、总摘要 3,000 tokens、单页 600 tokens；来源收集最多保留 10 个去重候选、单条摘要 2,400 字符，最终每条回答最多展示 5 条。模型仅根据真实搜索摘要解释和延伸，不声称应用已抓取全文。
- 每个模型步骤前检查持久取消状态；原生搜索复用整轮 AbortSignal 和 120 秒执行期限，不再设置包装层的 30 秒搜索期限。已观测到两次搜索后，后续步骤关闭搜索工具；真实工具调用纳入步骤边界的总预算。相同步骤内供应商已发出的调用无法逐个用本地 execute 拦截，不能宣称这是严格的供应商调用次数上限。
- 最终回答通过 `webSourceIds` 选择实际使用的结果；服务端拒绝未知编号，去重后每条回答最多 5 条。URL 只接受无嵌入凭据的 HTTP/HTTPS，去掉 fragment 后去重。
- 使用官方安装的 AI Elements `Sources`、`SourcesTrigger`、`SourcesContent`、`Source`，提供中文计数、展开和链接。本地引用与原图展示复用已验收链路。
- 网页来源随 `run_completed` 与最终消息在同一事务保存；SSE 和历史回放共用状态转换，刷新后恢复来源。不新增数据库表或迁移。
- 搜索启动、完成、无结果和失败进入已有过程区与持久事件；失败不会冒充无结果。未新增审计流水线、URL Fetch、监控页面或 MCP 功能。

## 边界

- 主模型指令要求只搜索最小公开关键词，禁止外发私人原文、个人信息和完整历史；原生供应商工具没有本地 execute，已移除包装层的查询正则拦截和重复查询集合，不再宣称程序能在搜索发出前逐条验证或去重。既有云模型调用本身仍按原聊天机制接收上下文。
- 应用侧限制请求次数、时限、结果和输出长度；Gateway 内部执行及已经发出的上游请求不能由本地代码保证立即终止或完全观测，不承诺取消后撤销已产生费用。过程事件记录应用工具调用，不伪造供应商内部次数或精确费用。
- 本轮没有修改或重新验收既有知识库内容；没有执行真实搜索服务断网、限流或超时注入，也没有执行线上部署验证。
