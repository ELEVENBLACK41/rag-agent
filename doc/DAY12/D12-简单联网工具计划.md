# DAY12：简单联网工具

状态：范围已按用户 2026-09-17 的决定收敛，实现与本地验证完成，待用户验收。DAY11 已由用户确认验收。详见 [实施记录](D12-联网搜索实施记录.md)。

## 目标

给现有聊天 Agent 增加一个联网搜索工具，使模型能围绕问题补充外部信息、结合已有知识解释与延伸，并展示实际搜索返回的网页来源。联网提高信息覆盖，不保证推理正确；事实依据与模型推断应清楚区分。

## 最小范围

1. 复用已有聊天工具循环与 Gateway 搜索选型，不增加独立研究 Agent 或审计流程。
2. 沿用总计划的联网开关，默认关闭；开启后由模型按需搜索，不要求每条消息都联网。空知识库也能在授权后搜索公开信息。
3. 搜索只发送回答所需的最小公开查询，不把私人文档全文或完整会话历史作为搜索参数。
4. 从工具真实结果收集标题与 URL，按 URL 去重，每条回答最多展示 5 条；使用 AI Elements 的 Sources、SourcesTrigger、SourcesContent、Source，计数与展示数量一致。来源随回答保存，刷新及历史查看可恢复。
5. 只展示实际获得且与回答相关的来源，不补造链接，不为凑满 5 条展示无关结果；没有来源时不显示空来源区。本地文档引用继续使用现有来源抽屉。
6. 复用现有运行状态、取消与调用预算；保留搜索超时、错误提示和基本调用记录。失败或无结果不冒充搜索成功，不把搜索摘要说成完整网页核验。
7. 外部内容作为资料处理，不作为系统指令；来源链接校验 HTTP/HTTPS 协议。具体 SDK 参数与事件结构在实现时按已安装版本及官方文档核实。

## 删除的原定范围

不做主题审计、候选声明提取、有限冲突检测、对象/版本/时间对齐、独立 URL Fetch、官方文档映射工具、专门的外部取证报告或新增监控大屏。上述内容不自动顺延到其他阶段，若以后需要再单独讨论。

## 验收

- 关闭联网时不调用搜索；开启后模型能按问题选择搜索，并用结果补充回答。
- 一条回答包含最多 5 条去重来源，标题与链接来自真实结果；不足 5 条按实际数量显示。
- 来源使用 AI Elements 组件，可展开与点击，历史恢复后仍能查看。
- 无结果、超时、失败与取消如实呈现；不影响已验收的本地检索与来源查看。
- 不需要主题审计、冲突报告或额外网页抓取即可完成 DAY12 验收。

官方组件依据：[AI Elements Sources](https://elements.ai-sdk.dev/components/sources)。
