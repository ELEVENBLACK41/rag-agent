# D11 图片附件瀑布流与文档分离

## 实现范围

- 左侧增加「图片附件」入口 `/attachments`，沿用工作区持久侧栏、标题、主题变量和移动端导航。
- 知识库清单仅显示当前已发布快照中，版本状态为 indexed 且属于已注册可索引格式的文档；服务端返回 isQueryable，客户端不靠扩展名猜测可检索能力。
- 图片从文档清单移至独立图库，采用响应式多列瀑布流，保留图片原始比例。默认仅显示图片；悬停或键盘聚焦时，以透明背景信息层展示文件名、版本和大小，无背景模糊，不占额外高度或阻挡点击。触屏可点击原图预览查看完整信息。
- 每次返回最多 24 张图片的元数据；滚动哨兵触发后续分页，保留手动加载入口。单张图片进入视口附近后再挂载图片请求，并使用浏览器 lazy loading 和异步解码。
- 首屏及分页等待展示高低错落的主题色骨架；单图失败可重试，列表失败停止自动请求并允许重新加载。
- 点击卡片通过现有 shadcn Dialog 查看原图，支持 Escape 关闭并恢复卡片焦点。

## 接口和边界

- `/api/attachments` 复用已发布清单的路径去重逻辑，仅返回 PNG/JPEG 附件。后续页必须携带首屏快照，快照改变返回 409，要求刷新，避免混合版本。
- `/api/attachments/[fileVersionId]` 只返回当前工作区快照中仍有效的图片；非图片、未知版本或过期快照不能读取。
- 两个 API 均复用现有 local/preview 访问保护，production 不开放；参数由 Zod 在入口校验。
- 图片只经服务端私有存储接口读取，不返回 storageKey、本地路径或 Blob 地址；使用 private/no-store、nosniff 和 same-origin 响应头。
- 没有新增数据库表、依赖、模型调用或更改导入/检索逻辑。上传入口仍在知识库页面。

## 实际验证

- 本次修改文件 ESLint 与 `tsc --noEmit` 通过。
- 本地浏览器真实数据验证：知识库显示 3 个可查询文档，图库显示 5 张图片；观察到加载占位、真实图片和原图弹窗，Escape 可关闭。
- 实际 HTTP 检查覆盖图片字节与 MIME、禁用公共缓存、分页偏移、非法参数 400、错误快照 409、未知或非图片版本 404。
- 临时内存元数据样本验证 53 张图片分页为 24/24/5，无重复；快照变更拒绝。未写入测试文件或数据库。
- 独立检查复用的部署权限函数：local/preview 允许，production 与未配置模式拒绝。

## 当前限制

- 真实数据只有 5 张图片，尚未用超过 24 张真实图片完成浏览器连续滚动验收；窄屏和深色模式未做浏览器实测。
- 当前服务端先复用完整快照元数据清单再分页，不一次性读取图片字节；大规模知识库的数据库分页可在实际容量需要时单独优化。
- 图库展示原始上传 PNG/JPEG 附件，不包含 PDF 页面截图、Office 内嵌图片等派生资产；没有新增缩略图生成流程。
- 本次未执行上传、删除、部署或生产构建。
