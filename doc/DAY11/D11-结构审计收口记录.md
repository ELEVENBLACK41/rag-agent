# DAY11：结构审计收口

状态：实现与本地验证完成，用户于 2026-09-17 确认 DAY11 已验收。与本目录已有图片视觉索引、图片回答展示记录共同覆盖 D11。未部署线上。

## 本次交付

- 新增 `/audit`，聊天侧栏与知识库页面均有入口；支持读取持久报告、重新检查、类型筛选、来源抽屉、下载原文件、加载/空库/错误状态及取消等待。
- 导入批次发布成功后，由既有导入 Workflow 的独立步骤执行结构审计。检查当前已发布完整快照，而非只检查此次上传文件；不调用模型、Embedding 或搜索，不修改原文。
- 新增 `structure_audit_reports`，每个快照保留最近一次报告。报告记录规则版本、检查时间、快照、文件/文本/链接/比较数量、覆盖缺口与 Finding；Finding 包含类型、严重程度、来源版本及行号、依据、建议、置信等级和需人工确认标记。
- 审计步骤位于导入失败处理范围之外。索引已经发布后，审计失败不会把成功导入倒退成失败；没有可用报告时页面明确提示刷新或重新检查，不返回伪造的零问题。
- 删除产生新快照后，旧报告不会继续作为当前报告返回；新导入自动检查，删除后的新快照可在页面重新检查。

## 已实现规则

| 规则 | 实际行为 |
| --- | --- |
| 本地链接/附件缺失 | 支持普通行内 Markdown 链接、引用式链接、Wikilink/嵌入、别名；文案为“当前导入范围内未找到”，不认定原 Vault 损坏 |
| 路径与歧义 | 优先笔记目录，再 Vault 根，再唯一短文件名；Wiki 可省略 `.md`；合法父目录引用允许，越过 Vault 根、绝对路径、无效 URL 编码拒绝；同名多候选明确提示 |
| 标题与 Block ID | 从原始 Markdown 保留标题、常见 slug、重复标题序号、自文档锚点和区分大小写的 Block ID；目标未读取或解析不完整时不武断确认锚点失效 |
| 代码与注释 | 围栏、缩进代码、行内代码和 HTML 注释中的链接示例不当作正文引用；审计独立读原文，不修改已有检索切块或要求重新向量化 |
| 完全重复 | 比较当前快照不同路径文件的原始 SHA-256，分组展示，包括附件和二进制文档 |
| 近重复候选 | 仅 MD/TXT；NFKC、大小写和空白归一化后，字符五元组 Jaccard ≥ 0.85 生成候选，明确未验证；不宣称语义等价，不自动合并或删除 |
| 图片待核对 | 已解析到的 Markdown PNG/JPEG 当前版本没有视觉分析、分析失败/未完成或低置信度时显示提示；复用 Office/PDF 已存失败/低置信度状态，不补调模型 |

没有视觉记录时，只说明可能与数量/像素限制或前置失败有关，不能从“没有记录”反推某一个具体失败原因。未分析独立图片、未提取的 Office/PDF 图片不冒充已分析。

## 资源、权限与范围

- 最多检查 500 个文件、单文本 1 MB、总文本 10 MB、10,000 处引用、5,000 对近重复、500 项发现；视觉状态读取最多 2,000 条。超限明确显示部分检查，文件清单不完整时不据此误报链接缺失。
- 近重复只比较归一化后 80–20,000 字符的完整文本，不截断大文档后冒充全文比较。
- 来源接口校验参数、服务端工作区、当前已发布快照成员及逻辑删除/文件状态；读取后再次确认范围。跨空间、非成员和更新后的旧快照均不可读取。
- 浏览器不接触存储键；原文以 React 纯文本呈现，附件以 `attachment` + `nosniff` 下载，响应 `no-store`。抽屉最多 35 行，每行最多 2,000 字符；这只是定位预览，完整原文通过受同样校验的下载入口获取。
- 沿用 local / 受保护 Preview 访问边界，Production 仍关闭。正式 Owner/Visitor、TTL、旧报告保留策略等发布门禁继续归入后续阶段。
- 不联网核验外链；不检查 Office/PDF 内部链接，不提供完整 CommonMark/Obsidian 插件语法解析；复杂多行链接、扩展 HTML 和无法匹配的结构须人工核对。按 2026-09-17 用户决定，有限语义冲突、过期声明与主题外部取证不再列入 D12。
- “取消等待”中止浏览器请求；已经开始的服务端有界规则检查可能继续完成，界面如实说明，不冒充持久任务取消。
