## 改动

- 根布局组合 `WorkspaceShell`，统一持有左侧导航、会话目录和聊天状态。使用现有 React Context 与 Next.js 路由，没有新增依赖或状态库。
- `/chat`、`/chat/[conversationId]`、`/library`、`/audit` 的 URL 保持原样。左栏保持同一实例，右侧独立滚动；知识库和审计入口按当前路径高亮。
- 聊天页面移除自身的侧栏和移动端导航；知识库/审计页移除重复的跨页返回按钮，统一从左侧切换。
- 草稿和聊天订阅由公共布局保留。跳转管理页面不取消后台生成；新 Run 返回会话 ID 时，若用户已离开聊天页，不抢回当前 URL。
- 直接打开会话、侧栏切换及浏览器前进/后退按路径恢复；同一会话的原生 URL 更新不重复加载并打断流。显式“新建会话”仍清空草稿；切换会话清除来源抽屉选择。
- 小屏继续使用 shadcn Sheet，统一提供工作区入口；选中页面后自动关闭抽屉。
