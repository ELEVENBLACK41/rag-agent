# DAY3 最小聊天检索链路记录

状态：进行中。本地真实链路已完成；待部署 Preview，使用私有 Blob 完成 D1 的上传、读取、删除闭环后再标记 DAY3 完成。

## 已完成实现

- 使用 shadcn/ui 与 AI Elements 建立最小聊天工作台：单 Markdown 上传、导入状态、聊天输入、流式回答、行号引用、会话删除与文件删除。
- 新增独立 `messages` 表；用户消息、助手最终消息与 Run 分离持久化，助手引用以结构化 JSON 保存。
- 实现已发布快照上的问题 Embedding 与 pgvector 余弦检索；D3 固定取单文件最近的已发布快照，最多发送 6 个候选块给模型。
- 实现 `POST /api/chat`：创建会话与 Run、保存阶段事件、经 Gateway `alibaba/qwen3.7-flash` 流式生成，并将最终回答、Run 完成状态、完成事件放入同一事务。
- 实现 `GET /api/runs/[runId]/events`，可从指定序号补齐持久化的阶段和回答增量。
- 原始文件存储改为统一入口：本地使用受边界约束的私有目录；Preview 配置 `STORAGE_PROVIDER=blob` 时使用 Vercel 私有 Blob 的 `put/get/del`。
- Preview 模式的 D3 导入、状态与删除接口要求服务端 `PREVIEW_UPLOAD_TOKEN`；本地模式保持 D2 的单人开发入口。生产和公开体验模式仍拒绝该阶段接口。
