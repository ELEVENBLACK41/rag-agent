# DAY2 最小导入链路记录

状态：已完成。D2 最小数据模型、Drizzle 迁移、私有本地文件存储和 Markdown 持久化导入 Workflow 已实现；真实数据库迁移、完整导入以及两类进程中断恢复均已通过。

## 已完成实现

- 建立 `workspace`、`principal`、逻辑文件、不可变文件版本、索引快照、导入任务、Chunk、会话、Run 与 RunEvent 共 10 张业务表。
- 生成 Drizzle 初始迁移 `drizzle/0000_bumpy_cyclops.sql`；迁移会先确保 `pgvector` 的 `vector` 扩展存在，Embedding 维度固定为 1024。
- 实现本地私有文件存储。上传文件名不参与服务器磁盘路径，原始文件保存到 `DATA_DIR`（默认 `./data`，已忽略 Git）。
- 实现仅在 `APP_MODE=local` 可用的 `POST /api/imports/markdown`；D2 阶段仅接收 1–10 MB 的 UTF-8 `.md` 文件。
- 实现持久化步骤：读取原文件并按标题/段落切块 → 使用 Gateway `alibaba/qwen3-embedding-0.6b` 批量生成向量 → 事务发布文件版本、索引快照和导入状态。
- Workflow 中只传递 `importId`，文档正文从业务数据库和私有文件存储读取，不进入 Workflow 状态。
- 按最新 `AGENTS.md` 完成代码审查：D2 自维护代码文件已补齐中文注释、关键常量说明、JSDoc 参数说明与 `edit by：Sliye` 文件头。
- 导入接口现在强制只接收一个 `file` 字段；Workflow 调度失败或原始文件落盘失败时，导入记录会明确标记为 `failed`，不再返回或保留为看似已排队的状态。

## 当前限制

- 这是 D2 的最小本地 Markdown 路径，尚未实现浏览器上传 UI、Owner/Visitor 完整鉴权、Blob 存储、PDF/Office 解析或检索问答。
- 调用 Embedding 会将文本块发送到已配置的 AI Gateway；首次配置时的用户告知界面尚未实现，不能把当前接口开放给公开访客。
- 验收时加入的恢复探针和延迟均已删除，未保留在产品逻辑中。
