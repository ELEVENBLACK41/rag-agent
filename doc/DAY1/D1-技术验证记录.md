### Neon PostgreSQL

- 创建 Neon Free 项目 `vaultagent`，区域为 AWS Asia Pacific 1（Singapore）。
- 保留 `production` 主分支，并从其创建长期 `preview` 分支；两者分别对应 Vercel Production 与 Preview。
- Vercel 已为两个环境分别配置加密的 `DATABASE_URL`，不共享 Production 凭据给 Preview。
- Preview 直接查询确认 PostgreSQL 为 17.11、数据库为 `neondb`；与本地 PostgreSQL 17 主版本一致。
- Preview 与 Production 均执行 `CREATE EXTENSION IF NOT EXISTS vector`；Production 查询确认 `vector` 扩展版本为 0.8.0。

限制：Vercel 会阻止将标记为 Sensitive 的 `DATABASE_URL` 拉回本机，这是预期的安全行为。DAY3 Preview 已通过真实问答完成 Vercel Runtime 的 Preview 数据库连接与 pgvector 查询验证；不以 Neon 控制台验证替代运行时验证。
