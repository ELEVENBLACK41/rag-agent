# Gateway 聊天费用接入

状态：实现与本地真实调用验证完成。本次仅接聊天模型步骤费用，不扩展导入资源、独立 Embedding/rerank、搜索费用拆分或平台账单。

- 从每步 `onStepFinish` 的 `providerMetadata.gateway.cost` 读取 USD 金额，同时保存 `generationId`、来源和采集状态；不使用整轮累计结果再次相加，不叠加缓存/推理费用子项。
- 兼容有限非负数和十进制金额字符串。缺失或非法金额为 null，实际零保留为 0；未知费用不伪造成功。请求 ID 独立校验，原始供应商元数据不落库。
- 复用既有 Run + 步骤标识的唯一记录和汇总，无新增依赖或数据库迁移。
- 模型详情展示每步费用，Run 列表、会话与总览展示已知费用小计和已知/已记录步骤覆盖率。小额美元保留八位小数；更小的正数显示小于阈值，不四舍五入成零。
- 旧 Run 不回填、不猜测费用；取消或失败且没有费用响应的调用保持未知。这些小计不代表完整平台账单。

## 实际验证

- 22 项临时解析和汇总断言通过，覆盖缺失、空字符串、布尔、负数、非有限值、非法数字格式、真实零、数字/字符串金额、请求 ID、显示精度和部分费用汇总。
- 使用现有本地聊天 API 与 Workflow 完成一次真实直接回答，1 个模型步骤，采集到 Gateway 返回费用 **0.00001268 USD** 和请求 ID；管理费用字段未混入聊天 SSE。
- 验收会话通过现有接口软删除，临时脚本和编译产物已移除；未操作用户其他会话。
- TypeScript 与定向 ESLint 验证通过。本次未修改依赖、路由或 Workflow 结构，不重复完整构建。

依据：[Vercel Gateway 响应费用说明](https://examples.vercel.com/academy/ai-gateway/ai-gateway-pricing)。本次未调用 Generation Lookup，也未声称与平台总账完成对账。
