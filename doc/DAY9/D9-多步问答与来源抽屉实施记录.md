# DAY9：受限多步问答与来源抽屉

状态：来源抽屉与直接检索问答已完成代码实现。2026-09-14 按最新决定，D9 的模型工具
循环暂不启用，问答恢复为 DAY8 的“检索候选 → 一次模型生成”路径；跨格式真实资料回归
仍未完成，当前不将其写作已验收。

## 实现范围

- 当前问答固定为：`retrievePublishedChunksWithTrace` 得到关键词、向量、RRF 与 rerank
  的最终候选后，一次性将候选正文作为受限上下文传给 `streamText`。模型不再发起
  `search_notes`、`read_sources` 或 `find_related` 工具调用。
- 检索与 rerank 仍保存 DAY8 约定的不含正文排序 Trace；引用编号与发送给模型的最终
  候选顺序一致，仍固定在创建 Run 时选择的快照。
- `lib/agent/` 与前端的工具活动展示暂时保留，便于后续基于评测决定是否恢复；
  当前生产问答路径没有导入或调用它们，也不产生工具事件。
- 新增 `lib/sources/` 和三个来源 API：预览、原始文件、视觉派生图片。每次读取都从
  `Run → Snapshot → Chunk → FileVersion` 重建授权关系，前端没有存储键或 Blob URL。
- 聊天引用改为可点击按钮，使用 shadcn `Sheet` 作为右侧来源抽屉；PDF 原文件按
  物理页打开，视觉来源展示对应派生图片。
- 来源抽屉的小屏保持全宽；桌面端使用 `88vw`、最大 `1440px`。宽度类使用与 shadcn
  `SheetContent` 相同的 `data-side` 选择器，确保不会被默认 `sm:max-w-sm` 覆盖。
