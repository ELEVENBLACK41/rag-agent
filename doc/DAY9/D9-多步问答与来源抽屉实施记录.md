# DAY9：受限多步问答与来源抽屉

状态：已完成代码实现、类型检查、定向 ESLint 与生产构建；跨格式的真实浏览器交互
复验待具备可用浏览器自动化工具和真实资料后执行，当前不将其写作已验收。

## 实现范围

- 新增 `lib/agent/`：每个 Run 单独创建 AI SDK `ToolLoopAgent`，固定在创建 Run 时
  选择的索引快照；不在模块级保存私有上下文。
- Agent 只开放 `search_notes`、`read_sources`、`find_related` 三个只读工具。首步强制
  搜索；`read_sources` 仅能读取本轮搜索返回的 Chunk，不能构造任意 Chunk ID。
- `VaultRunState` 限制最多 6 个模型步骤、5 次工具调用、每次读取最多 3 个 Chunk、
  每个 Chunk 最多 2,400 字符。最终引用只来自已成功读取的来源。
- 通过 AI SDK `fullStream` 发布脱敏工具活动；不持久化或渲染模型 reasoning、工具参数
  或工具正文。检索仍保存 DAY8 约定的不含正文排序 Trace。
- 新增 `lib/sources/` 和三个来源 API：预览、原始文件、视觉派生图片。每次读取都从
  `Run → Snapshot → Chunk → FileVersion` 重建授权关系，前端没有存储键或 Blob URL。
- 聊天引用改为可点击按钮，使用 shadcn `Sheet` 作为右侧来源抽屉；PDF 原文件按
  物理页打开，视觉来源展示对应派生图片。

## 文件职责

| 路径 | 职责 |
| --- | --- |
| `lib/agent/run-state.ts` | 当前 Run 的快照、候选访问范围、工具/文本预算与引用编号。 |
| `lib/agent/tools.ts` | 三项有 Schema 约束的只读工具。 |
| `lib/agent/run-agent.ts` | 模型、步骤上限与 Agent 指令装配。 |
| `lib/sources/reader.ts` | 快照内 Chunk 读取及 Run 范围的来源授权。 |
| `app/api/runs/[runId]/sources/**` | 解析预览、PDF Range 原文件和视觉资产读取。 |
| `components/sources/source-drawer.tsx` | 右侧抽屉的加载、失败、文本、PDF 和视觉状态。 |
| `lib/chat/runs.ts` | Run 事件/最终消息编排与同一 Node 执行内的事件序号串行化。 |
