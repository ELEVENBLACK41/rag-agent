# DAY4 数据库模型图记录

## 已完成

- 根据 `lib/db/schema.ts` 与 Drizzle 迁移文件整理当前 PostgreSQL 数据库模型。
- 新增可直接粘贴到 dbdiagram.io 的 DBML 文件：`doc/vaultagent-schema.dbml`。
- 覆盖当前 11 张业务表、字段类型、主键、默认值、索引、唯一索引和真实外键关系。
- 为表、字段、向量字段和业务关系补充中文说明，便于阅读和后续讨论。

## 关键说明

- `chunks.embedding` 是 `vector(1024)`，对应 PostgreSQL 的 pgvector 扩展。
- `messages.run_id` 当前只有索引，没有数据库外键；DBML 中仅通过中文备注说明，没有绘制成真实 Ref。
- `imports.workflow_run_id` 是 Workflow 系统的外部运行标识，当前没有对应的本地业务表或数据库外键。
- `runs.snapshot_id` 删除父快照时使用 PostgreSQL `NO ACTION`，其余关系按现有迁移文件保留级联删除策略。

## 验证

- 对照 `lib/db/schema.ts` 和 `drizzle/0000_bumpy_cyclops.sql`、`drizzle/0001_wonderful_adam_warlock.sql` 检查表数量、字段和关系。
- DBML 仅使用 dbdiagram.io 常用语法；时间字段使用实际 PostgreSQL 类型 `timestamp with time zone`。
