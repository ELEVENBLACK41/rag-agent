# DAY10 移除正文引用标记兼容

用户明确不需要兼容旧引用格式，要求删除正文中方括号引用序号的相关处理。本记录取代此前实施记录中有关旧标记解码、隐藏和格式分流的说明。

- 删除 `getVisibleAnswer`、`legacyCitationMarkers` 及其调用、历史恢复和类型字段。
- 删除本轮尝试添加的正则过滤、流式前缀缓存与正文清理逻辑。
- 消息正文直接渲染 `message.content`；历史上下文直接使用已保存正文，不再额外查询事件格式来区分新旧引用协议。
- 保留独立 `answer` / `citationIds` 输出契约与来源归属校验。底部来源卡片、原文定位不受影响。
- 不改写历史数据库内容，因此已保存到正文中的标记不会自动消失；本次也未声称通过删除兼容代码即可保证模型绝不生成标记。

验证：定向 ESLint 与沙箱外 `pnpm exec tsc --noEmit` 通过；删除的函数和字段在 `lib`、`components`、`workflows`、`evals` 中无残留调用。没有调用模型或改写会话数据。
